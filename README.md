- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Payment:** Stripe API

### 📦 Installation

```bash
# Clone the repository
git clone https://github.com/abdul-docs/sample-readme-ecommerce.git

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Run the app
npm start
